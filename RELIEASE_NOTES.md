# Git Assist v0.1.0 — First Public Preview 🤖

## What's included

- Telegram bot foundation
- GitHub username flow
- Public repository browsing
- Active repository selection
- Repository information
- Open issues
- Open pull requests
- Recent commits
- Reply and inline keyboard navigation
- Basic in-memory user session/state management

## Known limitations

- Public repositories only
- User/session state is stored in memory and is reset when the bot restarts
- Pagination is not implemented yet
- Issue/PR/Commit detail pages are planned for the next iteration
- Error handling and GitHub rate-limit handling will be improved in upcoming releases

## What's next

- Issue details
- Pull request details
- Commit details
- Better inline navigation
- Search and pagination
